# PlayRush

منصة ألعاب جماعية لحظية (Real-time) بواجهة عربية أولاً — تحدَّ أصدقاءك أو لاعبين عشوائيين في
مجموعة ألعاب معلومات وذكاء عبر الويب أو تطبيق أندرويد.

## الألعاب المتوفرة

| اللعبة | الوصف |
|---|---|
| 🔤 **خلية الحروف** | لعبة سيطرة استراتيجية على لوحة سداسية — أجب صح لتسيطر على الخلية. |
| ⚽ **مسيرة لاعب** | خمّن اسم لاعب كرة قدم من خلال الأندية التي لعب لها بالترتيب. |
| 🏦 **بنك** | سلسلة إجابات متتالية — احفظ رصيدك بـ"بنك" قبل أن تخطئ وتخسر كل شيء. |
| 🎭 **من أنا** | خمّن الشخصية من تلميحات متتالية. |
| 🧠 **معلومات عامة** | أسئلة معلومات عامة كلاسيكية بنظام تنافسي. |

يدعم كل لعبة أونلاين (ضد لاعب حقيقي، عام أو خاص) ووضعاً فردياً ضد بوت بعدة مستويات صعوبة
(حالياً: خلية الحروف ومسيرة لاعب).

## التقنيات

- **الباك اند**: FastAPI + Socket.IO (Python 3.12)، PostgreSQL، Redis اختياري للتوسّع متعدد
  العمّال.
- **الفرونت اند**: HTML/CSS/JS ثابت بدون إطار عمل أو أداة بناء.
- **تطبيق الجوال**: يغلّف الفرونت اند نفسه عبر Capacitor لأندرويد.
- **الذكاء الاصطناعي**: Gemini كحكم اختياري للإجابات النصية الحرة.

## هيكل المستودع

```
Backend/     FastAPI + Socket.IO server (app/)، سكربتات صيانة (scripts/)، إعداد النشر
FrontEnd/    الموقع الثابت (يُخدَّم كما هو، ويُعبَّأ أيضاً داخل تطبيق أندرويد)
android/     مشروع Capacitor (شبه مولَّد آلياً — عدّل capacitor.config.json بالجذر بدلاً منه)
```

## التشغيل محلياً

### الباك اند
```bash
cd Backend
pip install -r requirements.txt
cp .env.example .env    # واضبط القيم — DATABASE_URL (PostgreSQL) و SECRET_KEY إلزاميان
python run_dev.py       # http://localhost:8000، مع إعادة تحميل تلقائية
```

### الفرونت اند
لا يحتاج بناء — اخدم `FrontEnd/` بأي سيرفر ثابت. الاتصال بالباك اند يُكتشف تلقائياً
(`FrontEnd/js/config.js`) حسب البيئة (محلي/شبكة الجوال/إنتاج).

### تطبيق أندرويد
```bash
npm install
npm run cap:add:android     # مرة واحدة فقط
npm run cap:sync            # ينسخ FrontEnd/ داخل مشروع أندرويد بعد أي تعديل
npm run cap:open:android    # يفتح المشروع في Android Studio
```

## النشر

- الباك اند: Azure App Service، عبر GitHub Actions عند أي push لمسار `Backend/**`.
- الفرونت اند: Cloudflare Pages، ينتشر تلقائياً عند أي push.

## ملاحظات للمساهمين

- التعليقات ورسائل الـlog بالباك اند مكتوبة بالعربي — حافظ على هذا الأسلوب عند التعديل.
- لا يوجد اختبارات آلية حالياً؛ سكربتات فحص يدوية موجودة تحت `Backend/scripts/`.
- التفاصيل المعمارية الكاملة (تسجيل الأحداث، إطار الألعاب، التوسّع، إلخ) موثّقة في
